Square pixels — corrected approach

Tiny image dimensions must match the container's aspect ratio so each pixel cell is square when scaled up.

❌ Before (stretched)
16×4 stretched tall → rect pixels
16×4 stretched wide → rect pixels
✅ After (square pixels)
16×21 → square pixels ✓
16×10 → square pixels ✓

Implementation

// compute tiny dimensions that preserve aspect ratio
const tinyW = 16
const tinyH = Math.round(16 / item.aspectRatio)

// e.g. 3:2 image → 16×11 portrait 2:3 → 16×24 1:1 → 16×16
// when scaled up to fill container → each pixel cell is square

Same logic applies to the showreel slides. The tiny image always has the same ratio as its container → no stretching.
