How to implement the pixelated effect

Two approaches — the core technique determines how the "pixelated → clear" animation works for both the grid and the showreel.

TWO-LAYER STACK
TINY IMAGE · 16px wide · nearest-neighbor scaled
→ On card open / showreel transition: pixelated layer fades out, full-res beneath fades in simultaneously

A — Two-layer (tiny img + full-res, stacked)

Render a 16px-wide Next.js Image on top with image-rendering: pixelated. Full-res image sits beneath. Crossfade with Framer Motion. Reliable across all image sources and CDNs.

SINGLE IMAGE · sizes= trick
sizes="16px" → browser fetches 16px src
CSS: image-rendering: pixelated
→ resize container to trigger
a new fetch at full size
⚠ Animating "pixelated → clear" requires triggering a new image fetch mid-animation (causes flash)

B — Single image, dynamic sizes prop

One <Image>, switch sizes from "16px" to normal on open. Simpler markup but changing sizes causes a new network request mid-transition — potential visible flash.

⭐ Recommendation: A — Two-layer stack. More elements but zero flash, smooth Framer Motion crossfade, works with any image source.
